# Slskd

Homepage: [https://github.com/slskd/slskd](https://github.com/slskd/slskd)

A modern client-server application for the Soulseek file-sharing network.

## Usage

Set `slskd_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The Slskd web interface can be found at [http://ansible_nas_host_or_ip:5030](http://ansible_nas_host_or_ip:5030).
